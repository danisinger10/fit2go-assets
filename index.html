FAQs

Do I need a wearable?

No — but it helps. If you have one, we’ll use it. If not, we can still run Smart Training using simpler inputs (sleep + activity + session performance).

What if my wearable data is messy?

We only track one or two signals and look at trends week to week — not single-day spikes.

What if my schedule changes or I travel?

We shrink and simplify the plan for that week, so you still bank a win and keep momentum.

How long is a phase?

4 weeks. You’ll get weekly check-ins and a strength metric update every 4 weeks.

Is this medical advice?

No. Wearable data is used for coaching only. If anything looks concerning, we’ll recommend you speak with a clinician.
